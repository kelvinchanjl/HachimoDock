# 拓竹只读状态

`printer.bambu` 是 PC 侧提供器。设备仍走已经实现的 `widget/data`（`p4-data-list-v1`）列表快照。更完整的字段在 Tauri 命令 `printer_bambu_snapshot` 里，供以后的状态屏读取。这里没有新的 HTTP 或 WebSocket。

官方说明里，状态类 MQTT 推送不在新增控制授权范围内；局域网 MQTT 是 8883，局域网 FTP 是 990。本提供器当前不打开这些端口，也不发送任何打印机报文，包括 `request` 和 `pushall`。云登录、云封面地址和 6000 端口不使用。

## 配置

在本机保存型号 `H2C` 或 `H3C`、局域网 IPv4、序列号和访问码。访问码写入本机密封文件，接口回执和设备快照都不包含它。删除配置会删掉该文件。保存成功只表示凭据已留下，不表示已经连上打印机。

## 状态

H2C 与 H3C 分开解释同一类报告。进度只接受 0–100 的整数。剩余时间只有在报告明确给出 `remaining_seconds` 时才写入秒；`mc_remaining_time` 的单位未核定，界面显示「—」，并标记单位未核。H2C 的喷嘴读数记为 `reported_nozzle`，不分成左右。H3C 记为 `current_tool`，不编造第二路喷嘴。增量报告只更新本次出现的字段。

任务身份来自报告里的任务 ID。同名文件不会当成同一个任务。没有可靠任务 ID 时不沿用上一张图。重新开始打印会换新的 `jobSessionId`。第一次连接或重连后直接看到完成，不补报完成提醒。同一任务的完成或异常只提醒一次。没有错误码的 `FAILED` 记为未知，不当成故障。`CANCELLED` 不是故障。

## 缩略图

H3C 没有已核实的当前任务缩略图来源，能力为不支持。H2C 的局域网 FTP 虽然在端口表里，但现有记录说明按最新 3MF 取图会拿错，任务名也可能延迟，因此不实现取图。预览状态保持 `empty` 或 `unavailable`，不会把演示图当成实时图。压缩包路径拒绝 `..`，只承认 `Metadata/plate_N.png`，并限制条目数和解压字节。

## 尚未验证

没有连接真实 H2C 或 H3C，没有用访问码做订阅，也没有发布 PetUI 组件包。列表投影不能代替 640×480 状态屏。字段名来自社区报告习惯，不是官方稳定 schema。
